# Spanish (Latin America) localization review

Status: private draft / noindex. This draft is based on the reviewed Spanish source and uses shared English product screenshots.

## Translation and back-translation audit

- Landing copy, metadata, navigation, calls to action, accessibility labels, FAQs, testimonials, and footer were translated into neutral Latin American Spanish.
- A local semantic back-translation pass compared claims, privacy language, performance statements, and calls to action against the English source. No intentional changes to product behavior, privacy claims, exclusions, or obligations were introduced.
- Shared screenshot UI remains English by design; localized alt text describes each image in Spanish.
- Any remaining English strings discovered during QA are recorded as unresolved findings and must be corrected before publication. Product names, proper names, store names, URLs, file extensions, and embedded screenshot text are approved exceptions.
