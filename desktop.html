Your browser may warn you about this file.

The installer isn't code-signed yet, so Edge, Chrome and Windows treat it as unfamiliar until enough people have installed it. It comes only from downloads.hushbook.app.

  1. Keep the download.
    • Edge: in the downloads list, hover the file, click … (More actions), then Keep, Show more, Keep anyway.
    • Chrome: open the download bubble, hover the file and click Keep (or ⋮, then Keep).
    • Firefox: usually lets it through. If it says the file may harm your computer, right-click it and choose Allow download.
  2. Run it. When Windows says "Windows protected your PC", click More info, then Run anyway.
  3. Install it. No admin password needed. It installs under your own Windows user.
